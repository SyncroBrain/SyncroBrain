# 10 分钟 Cloud Lite 演示脚本（Build）

> 对象：集成商 / 企业 IT。禁止先讲链上、生态宫格。权威步骤也写在 [../build.md](../build.md) §5。

1. **（30 s）承诺**  
   「基于 ThingsBoard CE。30 分钟起演示，7 天内交付可私有化的设备、遥测、规则、告警底座。」

2. **（2 min）Compose 起来**  
   打开 Console：项目、Pack、运行时状态（TB 已连接）。

3. **（3 min）加载 `cold-lab` 参考 Pack**  
   看到 Device Profile / 看板；启动模拟器，温度曲线出现。

4. **（2 min）告警**  
   触发超温 → Alarm → 确认。说明：运行时是 TB；Pack 与许可走 SyncroBrain。

5. **（2 min）下一步**  
   导出 CSV；说明商业许可与年支持，不是免费无限定制。  
   若对方是实验室冷藏，再切 [gap-diagnosis.md](../../playbooks/gap-diagnosis.md)。
