# Validation 第 1–2 周作业包

> 配套手册：[../validation.md](../validation.md)  
> **本周不做**：iot-gateway 领域重构、ThingsBoard、DataTalk、原生 App。

## 今天先做哪三件事

1. **锁定 1 个生物医药园区**（名录进证据夹，不进 git）。
2. **约本周 5 次 QA/实验室运营访谈**（用下面日志表，没记录不计 30）。
3. **带两份样例去谈**：差距诊断模板 + 虚构月报，而不是架构图。

销售钩子：48 小时冷藏合规差距诊断，¥3,000–5,000，签试点可抵扣。

## 本周门槛（第 12 天自检）

| 门槛 | 达标？ |
|------|--------|
| 访谈 ≥15（本阶段前 2 周目标） | |
| ≥8 人确认同一高频痛点（抄表/告警无人认/审计慢 三选一须集中） | |
| ≥3 人对 ¥9,800–19,800 / 10 点 / 30 天不立即拒绝 | |
| 台架或纸面演练：超温至少 1 次可讲清楚 | |

未达标：继续访谈，**不要**开工 Cloud Lite。

## 访谈日志（复制行；真数据放 evidence/）

|------|-----------|------|----------|----------|--------------|----------|------------|----------|--------------|------|
| | | QA / 运营 / 设施 | 纸/Excel/App/无 | | | | 是/否/未知 | | 是/否/未知 | |

量化：人工抄表 min/天、告警确认 min、误报感知。未知就写「未知」。

## 账户清单列

园区、机构、ICP 是否命中（民营/20–200 台/非医院招标）、入口来源（名录/经销商/校准所）、触达日、下步（访谈/现场/诊断报价/放弃）。

首批 ≤100，**同一园区优先**。

## 设计伙伴（第 3–4 周才计数）

邮件意向 + 指定 QA 对接 + 不要求第二套互不兼容 SOP。聊天不算。
