# 渠道与产品验证附录

> **不是当前阶段门。** 当前是 **Product Iterate**，见 [product-iterate.md](./product-iterate.md)。  
> 本文用于闭门触达 / First Revenue：零预算触达技术买方与付费信号。  
> **不阻塞**产品打磨。实验室 30 人访谈不再作为写代码前提。

原则：有机会就收集反馈；没有访谈也不停工。主产品是 TB Cloud Lite 交付，不是先卖 ColdGuard 合规 SaaS。

## 1. 目标与停止条件

| 必须拿到 | 数字 |
|----------|------|
| 访谈（QA / 实验室运营） | ≥30 |
| 设计伙伴（给现场或数据） | ≥5 |
| 愿付试点费 | ≥3 家 |
| 同一高频痛点被独立确认 | ≥8 人 |

**停止条件**（命中即停扩功能、换垂直）：

- 30 次访谈后仍无 3 家愿付试点费；或
- 已谈的 3 个意向试点要求**不能被同一 Industry Pack 覆盖**的工作流。

不得用「市场教育需要时间」解释没有购买意愿。

## 2. 时间表

| 时间 | 创始人 | 产品 | 退出门槛 |
|------|--------|------|----------|
| 第 1–2 周 | 锁定 1 个生物医药园区；访谈 15 位 QA/实验室负责人 | Figma / 报告样例 + 硬件台架 | ≥8 人确认同一高频痛点；≥3 人接受价格区间 |
| 第 3–4 周 | 再访谈 15 家；签 5 个设计伙伴意向 | 告警演练、断网缓存、审计报告**原型** | 5 家给数据或现场；≥3 家愿付试点费 |
| 第 2–3 月 | 创始人亲自成交 3 个付费试点 | 只支持 1–2 类传感器、1 个 Pack | 3 家付费；上线 ≤10 工作日；告警到达可验证 |

第 4–6 月属 **Wedge**（转年约、渠道、标准化安装），见 [README.md](./README.md)，不在本手册提前开工。

## 3. 每周节奏

从一个园区名录建账户清单，**不做全国投放**。

| 动作 | 每周下限 |
|------|----------|
| 有效触达 | 20 |
| 访谈 | 5 |
| 现场 | 2 |
| 报价（诊断或试点） | 1 |

入口伙伴：冰箱经销商、计量校准机构、弱电集成商、LIMS 顾问。给 QA 的钩子：48 小时「冷藏合规差距诊断」（可抵扣试点费）。

## 4. 访谈提纲（必问）

每次访谈记：日期、园区/机构、角色、是否愿付费、原话摘录。未记录的访谈不计入 30。

1. 现在怎么记温度？纸质 / Excel / 厂商 App / 无。
2. 最近一次超温或断电发生了什么？谁在下班后被叫起来？
3. 上次审计要了哪些证据？准备了多久？缺什么？
4. 冰箱品牌与数量？校准谁做、证书放哪？
5. 告警现在发到微信群还是短信？无人确认怎么办？
6. 决策人是谁？预算科目？是否必须招标？
7. 对「¥1–2 万 / 10 点 / 30 天付费验证」的第一反应？
8. 数据能否出园区？若不能，私有化是否硬条件？

量化对比（有数就记，没有就标「未知」）：人工抄表时长、告警确认时长、审计准备时长、误报感知。

## 5. 差距诊断交付物（2 天）

输出一份可给 QA 的短报告，结构固定：

1. 资产盘点（品牌、容积档、有无探头/门磁）
2. 现状工作流（抄表 → 告警 → 审计）
3. 风险热图（超温/门开/断电/离线/校准过期）
4. 审计证据缺口（事件、确认人、校准、导出）
5. 建议试点范围（≤10 点）与报价
6. **明确写**：诊断不是免费无限 POC；签试点可抵扣

现场照片与许可范围内的样例记录归档到内部证据夹，不进公开仓。

## 6. 设计伙伴准入

同时满足才算设计伙伴，不算「聊过的朋友」：

- 书面或邮件意向：提供现场或历史温度数据；且
- 指定一名 QA/运营对接人；且
- 不要求同期定制互不兼容的第二套 SOP。

## 7. 本阶段产品允许做什么

| 允许 | 禁止 |
|------|------|
| 报告 PDF/Figma 样例 | 默认部署 ThingsBoard + DataTalk |
| 1 类认证温度探头 + 1 类网关的台架 | 自研传感器、视频、原生 App |
| 演练用通知（至少 1 条真实通道：企微或短信） | 链上、Agent 市场、Decoder 商店 |
| Pack 默认阈值的纸面/配置文件 | 每客户一个 Git 分支 |

演练与 SLO 口径见 [spec/reliability.md](../spec/reliability.md)。默认阈值见 [spec/industry-pack.md](../spec/industry-pack.md)。

## 8. 证据夹（内部）

未备齐前，不得对外说「Validation 已完成」。

| 产物 | 形式 |
|------|------|
| 访谈日志 | ≥30 条，含是否愿付费 |
| 园区账户清单 | 首批目标 ≤100，同一园区优先 |
| 设计伙伴意向 | ≥5 |
| 试点报价/合同草稿 | ≥3 家价格被讨论 |
| 差距诊断样例 | ≥1 份可给客户看的模板 |
| 台架记录 | 超温、门开、断电、离线各至少 1 次演练日志 |
| 演示脚本 + 版本号 | 即使只是原型 |

工程仓未 clone 时，不得主张「系统已在生产运行」。见 [README.md](./README.md) 证据规则。

真访谈、报价、现场照片：只放 [evidence/](./validation/evidence/)，默认不提交。
